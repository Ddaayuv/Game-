# بوت تيليجرام لتحويل النص/الرابط إلى QR Code

بوت بسيط: يرسل المستخدم رابطاً أو نصاً، ويرد البوت بصورة QR Code.

## الملفات
- `bot.py` — كود البوت.
- `requirements.txt` — مكتبات بايثون المطلوبة.
- `Dockerfile` — لبناء صورة Docker (متوافق مع Railway).
- `railway.json` — إعدادات Railway (يجبر استخدام Dockerfile).
- `.env.example` — مثال لمتغير البيئة المطلوب.

## سبب مشكلة البناء السابقة ولماذا لن تتكرر هنا
الخطأ الذي ظهر لديك (`Package libcurl, required by virtual:world, not found`) يحدث عندما يحاول Dockerfile الخاص بمشروع **PHP** تثبيت امتداد `curl` عبر `docker-php-ext-install curl` بدون تثبيت حزمة `libcurl4-openssl-dev` و`pkg-config` أولاً في نظام التشغيل.

هذا المشروع الحالي **بايثون**، وليس PHP، لذا لا وجود لهذه المشكلة إطلاقاً؛ لكن للاحتياط، الـ Dockerfile هنا يثبّت مسبقاً حزم البناء الأساسية (`build-essential`, `libjpeg-dev`, `zlib1g-dev`) التي تحتاجها مكتبة Pillow (المستخدمة لإنشاء صور QR) حتى لا يفشل البناء لأي سبب مشابه.

## خطوات التشغيل

### 1) إنشاء بوت تيليجرام والحصول على التوكن
1. افتح تيليجرام وابحث عن [@BotFather](https://t.me/BotFather).
2. أرسل `/newbot` واتبع التعليمات.
3. انسخ التوكن (BOT_TOKEN) الذي يعطيك إياه.

### 2) التشغيل محلياً (اختياري للتجربة)
```bash
pip install -r requirements.txt
export BOT_TOKEN="التوكن_الخاص_بك"
python bot.py
```

### 3) النشر على Railway
1. ارفع هذا المجلد إلى مستودع GitHub جديد.
2. في Railway: New Project → Deploy from GitHub repo → اختر المستودع.
3. Railway سيكتشف `Dockerfile` تلقائياً ويبني المشروع.
4. من تبويب **Variables** في الخدمة، أضف متغير البيئة:
   - `BOT_TOKEN` = التوكن الذي حصلت عليه من BotFather
5. اضغط Deploy، وانتظر اكتمال البناء (سيظهر Success بدلاً من Failed).

### 4) تجربة البوت
افتح محادثة مع البوت في تيليجرام وأرسل `/start` ثم أرسل أي رابط أو نص، سيرد عليك بصورة QR فوراً.

## ملاحظات
- البوت يعمل بنظام `polling` (لا يحتاج webhook أو دومين عام)، وهذا مناسب تماماً لخطة Railway المجانية أو الأساسية.
- إذا أردت لاحقاً التحويل إلى webhook لتقليل الاستهلاك، أخبرني وسأعدل الكود.
